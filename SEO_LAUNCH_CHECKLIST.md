# SEO launch checklist

## Done in code
- [x] Unique title + description per page (set on navigation)
- [x] Canonical, og:*, twitter:* tags, updated per page
- [x] RealEstateAgent structured data (address, phone, email, areas served)
- [x] robots.txt with sitemap reference
- [x] sitemap.xml with all public pages (legal pages excluded)
- [x] Legal pages and 404 marked noindex
- [x] One h1 per page, alt text on images, lazy-loaded images with dimensions
- [x] SPA fallback via public/_redirects

## At launch
- [ ] Publish and connect royalinfrarealty.com
- [ ] Verify domain in Google Search Console and Bing Webmaster Tools
- [ ] Submit https://royalinfrarealty.com/sitemap.xml
- [ ] Link Google Business Profile to the site
- [ ] Test share previews (WhatsApp, LinkedIn, Facebook debugger)
- [ ] Run PageSpeed Insights on Home and one project page (target 90+ mobile)
- [ ] Replace AI images with originals and re-check alt text
